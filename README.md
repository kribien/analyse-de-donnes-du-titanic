# analyse-de-donnes-du-titanic
Prédiction de la survie sur le Titanic avec scikit-learn Projet d'apprentissage automatique (Machine Learning) prédisant les chances de survie des passagers du Titanic. Traitement complet des données brutes (imputation, encodage One-Hot, normalisation) via des pipelines scikit-learn et classification par Régression Logistique.
